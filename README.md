## Overview

The **QualiaDB / Webizen** ecosystem is a local-first, Rust- and WASM-native human-centric computing platform designed around a foundational premise: software running on a device has a fiduciary obligation to the **natural person** who owns and operates that hardware. Rather than treating human data, relationships, and creative works as platform-owned telemetry, the stack separates personal **Sanctuary** custody from cooperative **Permissive Commons** publishing, grounded in international human rights instruments (UDHR Article 27(2), ICESCR Article 15(1)(c)), moral rights, and cryptographic identifier separation.

**VibeScript** (`vibe-0.1` / `v0.02`, with `vibe-0.2` specification in [`ecopunk/docs/planning/tech/vibescript-0.2-specification.md`](../ecopunk/docs/planning/tech/vibescript-0.2-specification.md)) functions as a **deterministic, capability-bounded REPL and hot-reload scripting extension to Rust** that eliminates the ecosystem's dependency on JavaScript, Node.js, and the C++ V8 engine while supplying an array of modern semantic, scientific, deontic, and reactive features that JavaScript/V8 lacks.

- **Why VibeScript Replaces JavaScript/V8 as a Live REPL Extension to Rust:**
  - **Zero V8 / Zero Node.js / Zero JIT:** Traditional cross-platform apps embed V8 or a webview JS engine for dynamic scripting, bringing garbage-collection pauses, JIT security surfaces (and iOS/embedded JIT prohibitions), prototype-pollution vulnerabilities, untyped JSON serialization overhead, and an impedance mismatch with Rust's memory model. VibeScript is implemented in pure Rust (`qualiaDB/crates/vibe`) with a stable provider/memory/lifecycle SDK (`qualiaDB/crates/vibescript-abi`).
  - **Live REPL & Zero-Recompilation Hot-Edit Workflow (`vibe::session`, `eval_cell`, `load_program`, `vibe-bc-0.1`):** Compiled Rust supplies the high-performance native and WASM domain kernels, while VibeScript acts as Rust's interactive REPL and dynamic application/asset scripting layer (`source → parse → type/effect/budget check → checked AST or stack-based bytecode VM → evaluate`). Editing a `.vibe` script, reactive cell formula (`= expr`), or `present` UI/scene block takes effect immediately in memory **without recompiling Rust, invoking Cargo, regenerating WASM binaries, or running a JS bundler**.
- **Modern Language Capabilities Beyond JavaScript/V8:**
  1. **Static Effect Classes, Hardware Cycle/Arena Budgets & Deontic Interrupts (`EffectClass`, `BudgetClause`, `deontic_interrupt.rs`):**
